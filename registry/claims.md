# Claims registry

One line per key claim or number from every processed article, so a new article can be checked against everything already in the hub. The process-article skill appends here and searches here for conflicts before writing `conflicts.md`.

Columns: **Slug** (article) · **Topic** · **Claim** (one sentence, with the number and unit) · **Strength** (RCT / prospective / retrospective / review / textbook) · **Conflicts with** (slugs, `proffit`, or `—`).
